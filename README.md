# Personal AI Job Hunter

A modular, cost-efficient, personal job-hunting automation system designed for targeted software & AI engineering roles.

## Features (In Progress)
- **Phase 1**: Python Foundation & Project Structure
- **Phase 2**: Playwright Fundamentals & Safe Test Scraping
- **Phase 3+**: Multi-source Collection, Normalization, Matching, and Tracking

## Quickstart

### Prerequisites
- Python 3.12+

### Setup
```bash
# Clone the repository
git clone https://github.com/Shadow310524/jobHunter.git
cd Personal-AI-Job-Hunter

# Create and activate virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate

# Install dependencies in editable mode
pip install -e .[dev]

# Run tests
pytest
```
